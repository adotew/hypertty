# File icons

The JetBrains IDE "New UI" file type icons, used for the sidebar's file tree.

- Most icons come from [JetBrains/intellij-community](https://github.com/JetBrains/intellij-community)
  (`platform/icons/src/expui/fileTypes`, commit 8c82f38), Copyright 2000-2025
  JetBrains s.r.o. and contributors, licensed under the Apache License 2.0.
- Icons for languages that only ship with JetBrains plugins (Go, Rust, Zig,
  Kotlin, Makefile, ...) come from
  [ankddev/zed-jetbrains-newui-icons](https://github.com/ankddev/zed-jetbrains-newui-icons)
  (commit 9b4cd67), which is MIT/Apache-2.0 licensed.

`name.svg` is the light-theme variant, `name_dark.svg` the dark one.
